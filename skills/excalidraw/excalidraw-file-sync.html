Pair this canvas with a file on your disk

Edits here are written back to your .excalidraw file, and edits an agent makes to that file appear here. One document, two editors.

  • FOLDERGrant a folder once and every diagram inside opens with no dialog — including ones an agent creates later. A link like ?file=docs/arch.excalidraw then opens one straight from the URL.
  • DISKThe open file is polled about once a second. When its contents change, the canvas is replaced.
  • CANVASYour drawing is written back to the same file ~0.6s after you stop moving.
  • GITOutput is canonical — keys sorted, churning version counters pinned, 2-space indent, trailing newline — so a diff shows only what actually moved.
  • AGENTFolder-opened diagrams keep a compact .excs sibling in sync both ways — a small text form agents can diff and edit; either file wins by being newest, scene file first.
  • GUARDBoth directions compare that same canonical form, so a write never echoes back as a change. If the file moves while you draw, the file wins and your version stays recoverable.
